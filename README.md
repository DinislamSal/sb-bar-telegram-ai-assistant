# S&B Bar Telegram AI Assistant

Демонстрационный Telegram-проект для заведения общественного питания: консультант по меню, оформление заказа и передача заказа персоналу.

> Репозиторий предназначен для портфолио. Токены Telegram и GigaChat, идентификаторы рабочих чатов, данные клиентов, заказы и доступы к Google Sheets не публикуются.

## Что реализовано

- Telegram-бот с категориями меню и кнопочным сценарием заказа;
- добавление товаров в корзину и оформление заказа;
- выбор доставки или самовывоза;
- передача заказа в отдельный чат персонала;
- подтверждение заказа сотрудником и уведомление клиента;
- AI-консультант на базе GigaChat, который помогает подобрать блюда;
- адаптивный интерфейс Telegram Mini App с каталогом, корзиной, адресом доставки, телефоном и способом оплаты.

## Состав репозитория

- `miniapp/index.html` — клиентский прототип Telegram Mini App;
- `data/sample-menu.csv` — пример структуры каталога меню;
- `docs/architecture.md` — архитектура решения и пользовательские сценарии;
- `docs/order-schema.md` — обезличенная структура заказа;
- `.env.example` — перечень необходимых настроек без секретов.

## Статус компонентов

| Компонент | Статус |
| --- | --- |
| Кнопочный заказ через Telegram | Прототип протестирован по полному сценарию |
| Подтверждение заказа персоналом | Прототип протестирован |
| AI-консультант GigaChat | Рабочий прототип |
| Telegram Mini App | Клиентский интерфейс готов |
| Приём заказа из Mini App в n8n | Требует завершения интеграции |
| Экспорт n8n workflow | Пока не добавлен |

## Технологии

- Telegram Bot API и Telegram Web Apps API;
- n8n;
- JavaScript, HTML и CSS;
- Google Sheets;
- GigaChat API;
- REST API и webhooks.

## Основной сценарий

```text
Клиент → Telegram → меню / AI-консультант → корзина → оформление
       → n8n → таблица заказов → чат персонала → подтверждение
       → уведомление клиента
```

## Запуск Mini App

`miniapp/index.html` можно открыть как статическую страницу для просмотра интерфейса. Полная работа внутри Telegram требует HTTPS-хостинга и подключения URL через настройки Telegram-бота.

## Подход к разработке

Проект создан с применением AI-assisted development. Автор определял бизнес-сценарий, структуру меню и заказа, проектировал взаимодействие клиента и персонала, собирал автоматизацию в n8n, тестировал сквозные сценарии и устранял ошибки интеграций.

## Ограничения портфолио-версии

Рабочий n8n размещён отдельно и содержит секреты подключений, поэтому не копируется напрямую. Перед добавлением экспорта workflow из него необходимо удалить credentials, webhook-адреса, идентификаторы чатов и ссылки на рабочие таблицы.
