# Структура заказа

Портфолио-версия описывает только поля и не содержит реальные клиентские записи.

| Поле | Назначение | Пример |
| --- | --- | --- |
| `order_id` | Идентификатор заказа | `1001` |
| `created_at` | Дата и время создания | `2026-07-08T14:30:00+05:00` |
| `items` | Состав заказа | `Пицца × 1` |
| `total` | Итоговая сумма | `659` |
| `customer_name` | Имя, указанное клиентом | `Тестовый клиент` |
| `phone` | Контактный телефон | `+70000000000` |
| `fulfillment` | Доставка или самовывоз | `delivery` |
| `address` | Адрес при доставке | `Тестовый адрес` |
| `payment` | Выбранный способ оплаты | `card` |
| `status` | Текущее состояние | `new` |
| `telegram_chat_id` | Идентификатор чата клиента | `000000000` |

Для рабочей версии необходимо определить срок хранения персональных данных, ограничить доступ и исключить вывод телефонов и адресов в журналы.
